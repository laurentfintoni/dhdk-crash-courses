# DHDK crash courses - Project Management, DH Research Tools & Literacy
## 26/27 bibliography (Working list)

This is a list of all the links and sources used for the DHDK Crash Courses for Project Management and DH Research Tools & Literacy in a.y 2026-2027. They're grouped by theme, and include a mix of scholarly sources, articles, social media posts and practical tools all of which are obviously available for as long as the platform gods allow them to be. There is no consistent citation system in place, sorry if that's triggering. This is a working list, final version will be after the first year courses in January 2027. 

If you spot any errors please let me know, thank you! 🙏🏻
